# Decision log

Why ArperBird is the way it is — the reasoning that doesn't survive in code or
commit messages.

One file per decision, `NNNN-short-slug.md`, in order. Keep it short: the
decision, the options, why the others lost. Artefacts go in `assets/`.

Append-only. To reverse a decision, add a new entry that supersedes the old one
and link back — don't edit history.
